# 一括アップロードテストスクリプト

## 概要

各問題に50枚のダミー画像をアップロードして、問題ごとの象限分割が正しく機能するかをテストするスクリプトです。

## 使用方法

### 1. 環境変数の設定

`.env.local`に対象のMiroボードIDを設定してください：

```bash
MIRO_BOARD_ID=your-board-id-here
```

### 2. 開発サーバーの起動

別のターミナルでNext.jsの開発サーバーを起動してください：

```bash
pnpm dev
```

### 3. スクリプトの実行

```bash
pnpm run test:upload-bulk
```

## 動作仕様

- **画像数**: 各問題に50枚
- **バッチサイズ**: 5枚ずつアップロード
- **バッチ間待機**: 2秒
- **問題間待機**: 5秒
- **対象問題**: 最初の4問題

## 実行時間の目安

- 1問題あたり: 約2-3分
- 4問題合計: 約10-15分

## 期待される結果

Miroボード上で以下のように配置されます：

```
     第2象限          第1象限
    (問題2)          (問題1)
    50枚の画像       50枚の画像
  
    第3象限          第4象限
    (問題3)          (問題4)
    50枚の画像       50枚の画像
```

## 生成される画像

- サイズ: 400x400px
- 形式: PNG
- 内容: カラフルな背景 + 問題番号とインデックス番号

## トラブルシューティング

### エラー: 環境変数が設定されていません

```bash
# .env.localを確認してください
MIRO_BOARD_ID=xxxxx
```

### エラー: アクティブなユーザーが見つかりません

```bash
# ユーザーを作成してください
pnpm prisma:seed
```

### エラー: アップロード失敗

- 開発サーバーが起動しているか確認
- Miro APIのアクセストークンが有効か確認
- ネットワーク接続を確認

## カスタマイズ

`scripts/test-upload-bulk.ts`の`CONFIG`セクションで設定を変更できます：

```typescript
const CONFIG = {
  IMAGES_PER_PROBLEM: 50,          // 各問題の画像数
  BATCH_SIZE: 5,                    // バッチサイズ
  DELAY_BETWEEN_BATCHES: 2000,      // バッチ間待機（ms）
  DELAY_BETWEEN_PROBLEMS: 5000,     // 問題間待機（ms）
  // ...
};
```
